Static Website on AWS S3



A personal cloud portfolio site hosted entirely on AWS using S3 for storage.



AWS Services Used



• Amazon S3 — stores and serves the static HTML/CSS files

• S3 Bucket Policy — IAM policy granting public read access to objects



What I Learned



• Creating and configuring an S3 bucket for static website hosting

• Writing and applying an S3 bucket policy (JSON)

• AWS Free Tier usage and billing alerts
